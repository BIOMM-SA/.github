# .github

Repositório de configuração padrão da organização **BIOMM S/A - TI**.

Os arquivos aqui são aplicados automaticamente a todos os outros
repositórios da organização — não é necessário copiá-los individualmente.

## Conteúdo

- **`CONTRIBUTING.md`** — guia de contribuição: nomenclatura de repositórios,
  fluxo de commits/PR, padrões por categoria (`rmm-`, `app-`, `integ-`) e
  diretrizes de segurança
- **`PULL_REQUEST_TEMPLATE.md`** — template padrão exibido ao abrir um PR em
  qualquer repositório da org
- **`ISSUE_TEMPLATE/`** — templates padrão de Issue (bug e nova
  funcionalidade)

## Referência

Consulte o [CONTRIBUTING.md](./CONTRIBUTING.md) para o guia completo antes de
criar um novo repositório ou abrir uma contribuição.
